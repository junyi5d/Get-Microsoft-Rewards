## 📸 界面预览

新版界面采用紧凑卡片式悬浮窗：

- **收起状态**：经典白底礼盒图标，默认停靠左下角（可改为右下角）
- **展开状态**：顶部显示会员等级图标与名称（如「🥇 金牌会员」）和积分；等级优先读取 Rewards 页面实际展示
- **加载状态**：账户数据未返回时显示模糊骨架与加载动画，栏数与读取完成后保持一致
- **中部进度**：每日活动 / 必应搜索 / 日常任务 / 阅读任务（无日常任务时自动隐藏），统一按积分显示
- **主按钮**：每日、搜索、任务、阅读四个按钮单行排列，下方为一键全部执行；账户信息未读取完成前按钮不可点击
- **运行日志**：默认展开，点击标题可收起；任务有中文标题时优先显示中文
- **设置弹窗**：齿轮按钮打开，可调整图标位置与任务间隔；版本号旁为圆形检查更新按钮，保存按钮下方为可折叠的赞赏支持

## ✨ 功能特性

### 🎯 核心功能

- ✅ **每日活动** - 完成今日 3 个 每日活动，每个 10 积分，全部完成显示 30/30；次日预载活动不会提前计入
- ✅ **必应搜索** - 每次真实搜索 +3 积分，每日上限按等级区分（会员 15 / 银牌 30 / 金牌 60，对应 5 / 10 / 20 次），优先读取 DAPI 搜索卡的真实上限；搜索间隔 15–28 秒（偶发更长）
- ✅ **日常任务** - 按实际读取到的任务汇总积分（不同账号任务数不同），已完成任务默认计满积分
- ✅ **阅读任务** - 存在阅读赚分任务时单列按钮与进度条，每次 +3 分自动续读，最多 10 篇
- 🔐 **OAuth 数据源** - 账户、任务状态与积分优先来自 OAuth(DAPI)，页面 HTML 仅作标题与任务兜底
- 🚀 **一键全部执行** - 只挑选未完成的任务，随机顺序执行；有中文标题时运行日志同步使用中文；全部结束后自动领取剩余可领取积分（每日签到 + 进度已满未领取的卡片）

### 🎨 界面特色

- 🎁 **悬浮窗设计** - 礼盒图标可放置左下角或右下角
- 📊 **实时进度** - 显示会员等级图标与名称、积分，以及每日活动 / 搜索 / 任务进度
- ⏳ **折叠倒计时** - 倒计时收进状态栏，不再刷屏日志
- ⚙️ **设置弹窗** - 图形化调整图标位置、任务间隔；版本徽章旁可检查更新，保存按钮下方可折叠展开微信赞赏码
- 📝 **可折叠日志** - 默认展开显示当前步骤，可一键收起
- 🌙 **深色适配** - 自动跟随系统深色模式

### 🛡️ 安全特性

- 🔒 **本地运行** - 所有逻辑在浏览器本地执行
- 🎲 **随机间隔** - 每日活动与任务采用随机间隔，偶发长停顿，任务顺序也会打乱
- 🎭 **贴近真人** - 提交前随机停留、打开目标页后随机浏览时长，避免机械节奏
- 🌐 **热搜词库** - 使用真实热搜词，搜索更自然
- 🍪 **真实会话** - OAuth 授权仅保存在本地；页面请求复用浏览器登录态，不伪造 Cookie 头
- 💾 **进度保存** - 刷新页面不丢失进度，自动续接任务

## 🔁 自动化基准

脚本以 `rewards.bing.com/earn` 页面实际展示的可赚积分栏目为准，只保留网页可完成的类别：

| 按钮 / 进度条 | 对应页面栏目 | 处理方式与积分口径 |
| --- | --- | --- |
| 每日活动 | 今日「每日活动」 | 3 个活动，每个 10 积分；已完成卡片直接计入，只执行未完成项 |
| 必应搜索 | 必应搜索 | 每次 3 积分，每日上限按等级（会员 15 / 银牌 30 / 金牌 60），优先读 DAPI 搜索卡真实上限，间隔 15–28 秒 |
| 日常任务 | 「日常任务」板块 | 按实际读取到的任务汇总积分；已完成任务默认计满，任务随账号与完成情况变化 |
| 阅读任务 | 阅读赚分卡片 | 有任务时单独显示按钮与进度条，每次 3 积分，按任务间隔续读 |
| App / 移动端 / Xbox / 邀请好友 | 相关卡片 | 跳过，不纳入自动执行 |
| 升级里程碑 / 默认搜索引擎 | 「升级活动」板块 | 无法由网页脚本一次完成，跳过 |

> 一键全部执行只会选择当前未完成、且可获得积分的栏目，并以随机顺序执行，最后领取可领取积分，模拟真人操作节奏。
> 问卷 / 测验类任务需要人工选择答案，脚本只能尝试自动上报；仅限 必应应用App 的任务无法代做。

## 🎮 使用说明

### 基础使用
**访问 Bing**
   - 打开 <https://www.bing.com> 或 <https://rewards.bing.com>
   - 页面左下角会出现礼盒图标 🎁（可在设置中改到右下角）
1. **查看进度**
   - 点击礼盒图标展开面板（默认左下角）
   - 查看当前会员等级（如「金牌会员」）、积分、各项任务进度

2. **执行任务**
   - **每日活动**: 点击 `✅ 每日` 按钮（需授权），只执行今日未完成的每日活动
   - **搜索任务**: 点击 `🔍 搜索` 按钮，连续执行必应搜索直到达到当日等级上限（每次 3 积分，间隔较久）
   - **日常任务**: 点击 `🎯 任务` 按钮，执行日常任务板块中可完成且未完成的卡片
   - **阅读任务**: 有阅读赚分时点击 `📖 阅读`，按任务间隔自动续读直到拿满
   - **一键执行**: 点击 `🚀 一键全部执行` 按钮，自动挑选当前未完成的栏目，随机顺序执行

3. **调整设置**
   - 点击面板右上角齿轮按钮（或 Tampermonkey 菜单中的「Microsoft Rewards 设置」）
   - **图标位置**：左下角（默认） / 右下角
   - **任务间隔**：快速（1.2–2.5 秒）、推荐（2–4 秒）、保守（3.5–7 秒），每日活动 / 任务 / 阅读通用且每次随机
   - **微软授权**：显示当前授权状态（已授权 / 未授权），可一键重新授权
   - **关于**：与「关于」并排一行，左侧文字、右侧蓝色版本徽章与检查更新按钮；发现新版本后下方直接显示「更新到 vXXX」链接，点击即打开脚本安装页
   - **保存设置**：位于关于上方，设置调整后点击保存立即生效（无恢复默认按钮）
   - **赞赏支持**：位于「保存设置」按钮下方，默认折叠，点击 `🎁 赞赏支持` 展开或收起
   - 保存后立即生效

### 授权设置（账户数据与每日活动）

账户信息、任务状态与每日活动统一使用 Microsoft OAuth(DAPI)；页面 HTML 仅在需要补充任务与中文标题时使用：

**方法一：通过脚本界面**

1. 点击 `✅ 每日` 按钮
2. 首次使用，面板会显示授权区域
3. 点击 `🔗 获取授权码` 按钮
4. 在弹出的新窗口登录微软账号
5. 登录成功后，脚本会自动捕获跳转 URL 中的 `code` 并保存；若未自动保存，可复制完整 URL（包含 `code=M.xxx`）
6. 将 URL 粘贴到输入框，点击 `保存` 按钮
7. 再次点击每日按钮即可执行

**方法二：直接访问授权链接**

直接访问以下链接获取授权码：

👉 [点击这里获取授权码](https://login.live.com/oauth20_authorize.srf?client_id=0000000040170455\&scope=service::prod.rewardsplatform.microsoft.com::MBI_SSL\&response_type=code\&redirect_uri=https://login.live.com/oauth20_desktop.srf)

登录后复制跳转页面的完整 URL，粘贴到脚本面板的授权输入框即可。

> **提示**: 授权码会自动保存，下次使用无需重复授权（除非 Token 过期）。设置弹窗中可查看授权状态，并点击「重新授权」清除旧授权后重新获取。

## 🔧 高级配置

日常使用直接通过面板右上角的 **设置弹窗** 调整即可：

| 设置项  | 可选值           | 说明                                              |
| ---- | ------------- | ----------------------------------------------- |
| 图标位置 | 左下角（默认） / 右下角 | 悬浮图标的停靠位置                                       |
| 任务间隔 | 快速 / 推荐 / 保守  | 每日活动与任务的随机等待区间（1.2–2.5 / 2–4 / 3.5–7 秒），并会偶发额外长停顿 |

设置保存在 `GM_setValue` 中，刷新页面后依然生效。如需修改热搜源或预设区间，可编辑脚本中的 `CONFIG` 与 `PRESETS`：

```javascript
const PRESETS = {
    fast:        { label: '快速', taskMin: 1200, taskMax: 2500 },
    recommended: { label: '推荐', taskMin: 2000, taskMax: 4000 },
    safe:        { label: '保守', taskMin: 3500, taskMax: 7000 }
};
```

## ❓ 常见问题

### Q: 搜索任务没有积分？

**A**: 每次搜索 +3 积分，每日上限按等级区分（会员 15 / 银牌 30 / 金牌 60），脚本按当日上限执行对应次数，间隔 15–28 秒

- 检查账号是否被 **风控**；若上报未被接受，稍后再试

### Q: 日常任务显示「提交失败」？

**A**: 部分任务是问卷/测验，需要真实点击选项，脚本只能尝试自动上报

- 确认已登录 rewards.bing.com，并在面板中刷新一次数据
- 任务卡会依次尝试 App 接口、Server Action、旧接口，并回退访问任务页；若账号触发风控会失败

### Q: 为什么面板进度与卡片数量不同？

**A**: 各栏统一按积分统计，并非按执行个数显示

- 每日活动单任务 +10 积分，每日更新 3 个，全部完成显示 30/30
- 必应搜索每次 +3 积分，每日上限按等级（会员 15 / 银牌 30 / 金牌 60），优先读取 DAPI 搜索卡的真实上限
- 日常任务按当前账号实际读取到的任务积分汇总；已完成任务即使缺少进度字段也默认计满
- 阅读任务单独一栏，每次 +3 分，脚本会按剩余积分继续阅读（最多 10 篇）并遵循任务间隔
- 一次性任务完成后不再出现，因此不同账号、不同时间看到的任务总数会不同

### Q: 提示「篡改猴没有访问此页面的权限」？

**A**: 主要是在https://rewards.bing.com这个页面，也可以到https://cn.bing.com正常使用

### Q: 每日活动失败？

**A**: 确认已正确获取并保存授权码

1. 检查授权码是否过期（Token 有效期约 1 小时）
2. 尝试重新获取授权码
3. 若页面任务或中文标题缺失，刷新 rewards.bing.com 后重试

### Q: 如何卸载？

**A**: 打开 Tampermonkey 管理面板

- 找到 "Get Microsoft Rewards" 脚本
- 点击删除即可
